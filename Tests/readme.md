Sain sen toimimaan ottamalla timestampin klikattavaan päivään virhelogista, mutta kun tein simppelin date to timestamp python tiedoston tarkistaakseni. Se ei ollut luotettava tapa valita päivämäärää. Sen takia nykyinen asetelma. [Tehtävä3](Front/Demo/Teht3/report.html). Robot tiedosto löytyy [täältä](Front/Demo/Teht3/teht3_demo.robot)
